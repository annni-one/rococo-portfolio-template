# 🌸 Dripping Honey · 个人小站

> 我自宇宙万物的一切美好中诞生，走过漫长的岁月，只为在这个节点与你相遇，展开故事。

---

## ✨ 项目简介

这是一个**粉色复古洛可可芭蕾风格**的个人主页，为「魔法少女道士」兔梓量身打造。

融合了蕾丝信封、花卉刺绣、珍珠火漆、粉色蝴蝶结等复古元素，呈现一个温柔又神秘的个人世界——在职道士 / 现代萨满 / 萌豚阿宅，ENTJ 天蝎座。

## 🎀 设计风格

| 元素 | 说明 |
|------|------|
| **配色** | 米白底 + 浅粉点缀 + 珍珠白 + 淡金 + 深棕文字 |
| **字体** | Great Vibes（英文花体）+ Noto Serif SC（中文衬线） |
| **装饰** | 蕾丝边框、花卉刺绣信封、珍珠火漆、星座暗纹 |
| **质感** | 法式复古 × 魔法少女 × 神秘学氛围 |

## 📂 页面结构

### 1. 首页 Hero
- 心形蕾丝框里的兔子插画
- 英文花体标题 + 中文副标题
- 底部引言文字

### 2. 关于我 About Me
- 花卉刺绣蕾丝信封造型
- 身份标签：ENTJ / 天蝎座 / 双 / 在职道士 / 现代萨满 / 萌豚阿宅
- 「不如把我当作魔法少女✨」

### 3. 爱好与擅长 Hobbies & Skills
三张卡片：
- **宗教哲学** — 道教 / 印度教 / 萨满，通灵传讯 / 塔罗占卜 / 萨满疗愈 / 法事科仪 / 符箓
- **历史研究** — 中国史 / 近代史 / 苏联美学
- **游戏** — 英雄联盟 / 永劫无间 / 宝可梦 / 碧蓝航线 / 魂游系列

### 4. 联系我 Dear Visitor
- 珍珠 V 形蕾丝信封造型
- 邮箱 / 微信 / 小红书 / 地址

## 🛠 技术栈

- 纯 HTML / CSS / JavaScript 单文件
- 无框架、无构建工具
- Google Fonts 在线字体
- 响应式设计（桌面 + 移动端）

## 🚀 如何使用

```bash
# 克隆仓库
git clone https://github.com/你的用户名/dripping-honey.git

# 直接打开 index.html
# 或者用本地服务器打开
npx serve .
```

> 💡 背景音乐需要点击页面任意位置才会开始播放（浏览器自动播放限制）
